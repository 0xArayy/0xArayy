## Profile

Senior Blockchain Backend Engineer with **7+ years in software engineering**, including **5+ years building production blockchain and distributed systems**. I work across Solidity smart contracts, Go and TypeScript backend services, transaction infrastructure, indexers, and high-load event-driven systems.

## Selected Impact

- Architected Go and TypeScript blockchain services processing **10M+ on-chain events per day** with PostgreSQL, Redis, and Kafka.
- Built transaction infrastructure for simulation, nonce management, gas estimation, signing, broadcasting, confirmations, retries, and replacement transactions.
- Developed production indexers for blocks, transactions, logs, token transfers, and contract events, including historical backfills and chain reorganization handling.
- Delivered and upgraded Solidity systems across Ethereum, Base, and other EVM networks using Foundry, Hardhat, multisig-controlled releases, and on-chain verification.
- Strengthened smart contract security with fuzz, fork, integration, and upgrade testing, supported by Slither, Mythril, coverage analysis, and external audits.
- Built and deployed an **Avalanche L1 (CX Chain)** with validator and node infrastructure, plus cross-chain interoperability for contracts and applications.
- Improved distributed payment throughput from **under 10 to nearly 1,000 payments/sec** and worked on services handling **1M+ transactions per day**.
